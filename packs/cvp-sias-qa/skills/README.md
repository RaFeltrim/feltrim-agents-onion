## Por que estao no repo cliente

As skills sao acionadas pelo Cursor IDE quando se trabalha no repo cliente.
Manter no repo cliente garante:

- Caminhos relativos corretos para massas, evidencias e prints.
- Versionamento junto com o pack de evidencias.
- Disponibilidade automatica do Cursor quando se abre o repo.
