# Agent Observability Dashboard

Dashboard Web de Observabilidade e Telemetria em Tempo Real para o ecossistema Feltrim Agents Onion.

## Funcionalidades
- Monitoramento do Claude Code Router (porta 3456) e LM Studio (porta 1234).
- Painel de modelos ativos (DeepSeek R1 7B, Qwen 2.5 Coder 7B, Gemini 3.5 Flash Lite).
- Telemetria de memória e VRAM da GPU NVIDIA Quadro T1000.
- Interface Web moderna em Dark Mode com Glassmorphism.
